# the-willow-house
## The Willow House 

### Mediterranean-Inspired Boutique Hotel Website

## About This Project

The Willow House is a fictional boutique hotel website created as a hands-on HTML and CSS practice project.
The website showcases a Mediterranean-inspired retreat, featuring elegant accommodations, relaxing amenities, guest testimonials, and a responsive layout.

This project allowed me to practice building and redesigning a complete multi-section website.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Website Features
1. Responsive navigation
2. Full-screen hero section
3. Three accommodation cards
4. Amenities and wellness section
5. Guest testimonial section
6. Contact information
7. Mobile-friendly layouts

## What I Practiced
1. Structuring webpages using semantic HTML
2. Organizing content with containers and cards
3. Creating layouts with Flexbox and CSS Grid
4. Using media queries for different screen sizes
5. Improving typography, spacing, and visual consistency
6. Publishing a website using GitHub Pages
